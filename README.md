# Java Spring Boot Todo List Application

This is a simple Todo List REST API built with Java Spring Boot. The project was created for assessment to understand how a backend application connects the controller, service, repository, model, and MySQL database together.

The application allows users to create, read, update, delete, and filter tasks. The API was also tested using JUnit and MockMvc, and the test result report is included in this repository.

## Technologies Used

- Java 24
- Spring Boot 3.5.14
- Spring Web
- Spring Data JPA
- Spring Validation
- MySQL
- Maven
- JUnit 5
- MockMvc
- Postman
- IntelliJ IDEA

## Main Features

- Create a new task
- View all tasks
- View completed tasks
- View incomplete tasks
- Update an existing task
- Delete a task by ID
- Validate task input
- Handle errors with custom exception handling
- Test controller endpoints with JUnit and MockMvc

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/tasks/` | Get all tasks |
| `GET` | `/api/v1/tasks/completed` | Get all completed tasks |
| `GET` | `/api/v1/tasks/incomplete` | Get all incomplete tasks |
| `POST` | `/api/v1/tasks/` | Create a new task |
| `PUT` | `/api/v1/tasks/{id}` | Update an existing task by ID |
| `DELETE` | `/api/v1/tasks/{id}` | Delete a task by ID |

## Example JSON Request

```json
{

  "completed": false

```

## Database Configuration

This project uses MySQL. The real database credentials should be stored in a local `.env` file.

The `.env` file is not uploaded to GitHub because it may contain private database information.

Create a local `.env` file in the project root using this format:

```properties
DB_HOST=localhost
DB_PORT=3306
DB_NAME=todoapp
DB_USERNAME=your_mysql_username
DB_USER_PASSWORD=your_mysql_password
```

A safe example file is included as:

```text
.env.example
```

## Running the Application

From the project root, run:

```bash
./mvnw spring-boot:run
```

On Windows, run:

```bash
mvnw.cmd spring-boot:run
```

The application will start on the default Spring Boot port:

```text
http://localhost:8080
```

## Running the Tests

The controller tests are located in:

```text
src/test/java/com/example/todoapp/controller/TaskControllerTest.java
```

The test class uses the real MySQL database. It deletes all rows in the `task` table before and after each test so that every test starts clean.

To run the tests from the command line:

```bash
./mvnw test
```

On Windows:

```bash
mvnw.cmd test
```
